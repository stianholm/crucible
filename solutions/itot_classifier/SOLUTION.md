# itot_classifier

Generated by the onboarding wizard from the seven questions. Do not hand-edit
this file — re-run onboarding if an answer changes, except question three
(invocation), which is frozen forever once set.

## What should get better

Whether a proposed IT/OT integration gets routed to the correct gateway type (or correctly rejected) under Section 5 of the ITOT-boundary-as-architecture whitepaper — the four-way split between telemetry, engineering-data, operational-change, and the safety-wall, plus recognising the seven named anti-patterns.

## Artifact

A Python module with one entrypoint function that classifies an IntegrationProposal (touches_sis, needs_write, data_type, scope/approval flags, anti-pattern flags) into a Classification (gateway, approved, required_controls, anti_patterns_detected, reasoning).

## Invocation — FROZEN

def solve(task_input: str, ctx) -> str — task_input is JSON encoding an IntegrationProposal's fields; returns json.dumps(...) of the Classification fields (gateway, approved, required_controls, anti_patterns_detected, reasoning).

If this ever changes, every score in this solution's archive becomes
incomparable and the solution starts over. Onboard a new solution instead
of editing this.

## Mutation surface

Everything inside the EVOLVE-BLOCK markers in candidate/candidate.py — the full gateway-routing decision procedure and all seven anti-pattern checks. The solve() wrapper (JSON parse/serialise) and the entrypoint signature are frozen scaffolding.

The proposer may only rewrite what's between `EVOLVE-BLOCK-START` and
`EVOLVE-BLOCK-END` in `candidate/`. Everything else is frozen scaffolding.

## How good is told from bad

Whether gateway and approved match checks/reference.py exactly (each is pass/fail), and how closely the detected anti_patterns_detected set matches the reference set (partial credit via Jaccard overlap, since missing one of several anti-patterns is a smaller error than missing all of them). required_controls and reasoning are not auto-graded — free-form prose isn't reliably checkable without a judge, and this solution is meant to stay fully deterministic.
